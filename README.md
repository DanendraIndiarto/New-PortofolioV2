# Portfolio Website - Danendra Athallah Indiarto

Website portofolio pribadi modern untuk menampilkan profil, proyek backend, dan sertifikat profesional sebagai **Junior Backend Developer**.

## 🚀 Tech Stack
* **Frontend:** Next.js (App Router), React, Tailwind CSS
* **Backend & Database:** Supabase (Database relasional, Storage)
* **Core Skills:** Node.js (NestJS & Express.js), MySQL, Linux Ubuntu Server, PM2, CI/CD GitHub Actions

## ✨ Fitur Utama
* **Dynamic Content:** Data profil, proyek, dan sertifikat terintegrasi dengan Supabase.
* **Direct Communication:** Tautan langsung WhatsApp & Instagram serta form email Formspree.
* **Responsive Dark Theme:** Antarmuka bertema gelap yang bersih dan futuristik.
